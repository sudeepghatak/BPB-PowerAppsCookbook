## 🚀 Steps to Import a ZIP File

### 1. Open Power Apps Portal

* Navigate to: [https://make.powerapps.com](https://make.powerapps.com)
* Select the correct **environment** from the top-right corner

---

### 2. Go to Solutions

* In the left navigation pane, click **Solutions**
* This is where all apps, flows, and components are managed

---

### 3. Import Solution

* Click **Import solution** from the top menu
* Click **Browse** and select your ZIP file
* Click **Next**

---

### 4. Review Solution Details

* Verify solution name and version
* Click **Next**

---

### 5. Configure Connections (if required)

Some apps use connectors like SharePoint, Outlook, or Dataverse.

* Map required connections
* Create new connections if needed

---

### 6. Set Environment Variables (if applicable)

If the solution uses environment variables:

* Provide values for each variable
* Example: SharePoint site URL, API endpoints

---

### 7. Import

* Click **Import**
* Wait for the process to complete

⏳ This may take a few minutes depending on the solution size.

---

## ✅ After Import

Once the import is complete:

* Open the solution
* Verify apps, flows, and components
* Test the app functionality
* Publish any changes if needed
