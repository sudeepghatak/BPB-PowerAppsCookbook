# Chapter 9

This folder contains the PropertyMgmt Power Apps code app, built with React, TypeScript, and Vite.

The project source, generated Power Apps artifacts, and project-specific setup instructions are in [`PropertyMgmt/`](PropertyMgmt/). Start with its [README](PropertyMgmt/README.md) for prerequisites, Dataverse configuration, local development, and build instructions.

Full Dataverse functionality requires access to a compatible Power Apps host and environment. The project includes generated data source schemas and services that are environment-specific; see the project README before connecting it to another environment.
